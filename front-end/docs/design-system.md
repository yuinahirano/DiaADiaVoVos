# 🎨 Design System - Dia a Dia Vovôs

    Este documento define os padrões visuais e de interface do sistema "Dia a Dia Vovôs", focando na simplicidade e acessibilidade para o público da terceira idade.

---

# 🔤 Tipografia

A tipografia garante que as informações médicas e agendamentos sejam lidos sem esforço.

## 📌 Fonte principal

* **Font-family:** Inter, sans-serif (Alta legibilidade)

## 📌 Hierarquia

* **H1:** 32px / Bold (Títulos de Seção)
* **H2:** 24px / SemiBold (Subtítulos de Medicamentos/Consultas)
* **H3:** 16px / Medium (Nomes de Contatos e Legendas)
* **Body:** 16px / Regular (Texto padrão e Descrições)
* **Small:** 8px / Regular (Informações secundárias)

---

# 🧩 Componentes Especializados

## 🔘 Botão de Emergência (RF-006)

Funcionalidade crítica que permite o acionamento rápido para enviar alertas com localização aos contatos cadastrados.

* **Cor:** Danger Color (#F44336).
* 
**Estado:** Sempre acessível e de fácil identificação visual.



## 📦 Card de Informações Médicas (RF-005)

Container para agrupar e apresentar dados como tipo sanguíneo, alergias e histórico de doenças.

* 
**Uso:** Centralizar o perfil de saúde para consulta rápida do cuidador.



---

# 📐 Espaçamento e Grid

## 📏 Escala de Espaçamento

* **8px / 16px / 24px / 32px**
* 
**Regra:** Utilizar múltiplos de 8 para manter o layout organizado, reduzindo a carga cognitiva do usuário.



## 📊 Breakpoints (RNF-001)

O sistema deve garantir uma experiência consistente e acessível em diversos dispositivos:

* **Mobile:** 320px (Foco em usabilidade rápida e emergência).
* **Tablet:** 768px.
* **Desktop:** 1024px+ (Uso administrativo e gestão de relatórios).
